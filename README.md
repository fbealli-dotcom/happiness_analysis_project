World Happiness Analysis (2015-2019) 
This repository contains the data analysis and visualization project focused on the World Happiness Report. The goal of the project is to explore the socio-economic factors that influence global well-being and analyze specific national trends, such as the Italian case.
 Tools Used
Python (Pandas & NumPy): Data cleaning, merging, and statistical processing.
Google Colab: Cloud-based environment for development.
Flourish: For interactive maps and dynamic Line Chart Races.
datawrapper
RAWGraphs: For advanced structural visualizations (Radar and Stacked Bar charts).
GitHub: For version control and code transparency.

Project Workflow
The analysis followed these key steps:
Data Integration: Merged five annual datasets (2015-2019) into a single longitudinal dataframe.
Structural Decomposition: Normalized the six pillars (GDP, Social Support, Health, Freedom, Generosity, and Corruption) to evaluate their relative weights.

Trend Analysis:
Identified "Top Climbers" (e.g., Latvia, Benin) and nations in crisis (e.g., Venezuela).
Analyzed the Italian case, highlighting the decoupling between GDP and Happiness.
Comparative Analysis: Used Radar Charts to compare the structural "DNA" of extreme outliers like Finland and Venezuela.
statistical Correlation: Explored the nonlinear relationship between wealth (GDP) and life satisfaction, identifying specific "acceleration points."
